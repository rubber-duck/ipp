# Host Data Service

`DataService` owns typed buffer and streaming payload across Worlds under the [data architecture](../../../../../docs/architecture/data.md). It is separate from component Rows, Asset Management and generic byte I/O. Local producers and dataset adapters use the same validated admission API; codecs and transport queues belong outside this module.

`create_source` returns a `DataProducerHandle` fencing one incarnation. `apply_batch` consumes ordered `DataDelta` values and reports the committed prefix on failure. Rows receive `DataRowId` sequence numbers in commit order, including streaming arrivals immediately expired. Buffer positions and row identities are independent. Disconnect uses `detach_producer`; recreation by name invalidates old handles and re-resolves consumers. `destroy_source` explicitly removes a producer's source.

Bindings use `register_consumer`, `update_consumer` and `release_consumer` with a `DataConsumerIdentity` containing World, entity and binding lifetimes. Requests select a source name and kind. `DataWindow` constraints intersect within each consumer and their results unite for retention across Worlds. Numeric range windows inspect raw F32/I32/U32 columns in chosen units, with supplied, latest or Host-time anchors; no timestamp type is promised. The no-window default byte cap counts owned row descriptors, value capacity and conservatively counted text bytes. Explicit windows bypass it. Default windows also preserve a forward-moving row bookmark during idle expiry; explicit request or cap changes may expose still-retained history. Expiry cannot resurrect history. A streaming source without ready consumers retains no samples.

`validate_consumer_request` and `validate_window_update` preflight authored requests through the same nonmutating checks used by registration and updates. Missing sources and schema incompatibility remain availability states, rather than authoring failures. Failed validation changes neither demand nor pending notifications.

`consumer_state` reports missing sources, kind mismatches and invalid raw-column windows. `take_notification` consumes coalesced changed/availability flags at the World mutation boundary; the binding owns its separate presentation dirty flag. `read_source` borrows the retained union; `read_consumer` borrows that consumer's selection. `DataReadView::schema`, `rows` and `row` expose immutable typed storage without copying payload or retaining a runtime borrow beyond the callback. `DataSourceMemory` distinguishes retained samples, allocated row capacity and schema storage. Service-owned vector reservations report `Capacity`; caller construction and standard-library allocations outside this boundary remain the caller's responsibility. Asset-valued columns are rejected; bounded text and the other existing core value kinds are supported.

The Host advances elapsed time during scheduling, independently of World selection. `WorldContext::prepare_update` runs pre-ingress Check/Accept hooks before service progression; it does not freeze producer admission or define the final data visibility cut. Bindings consume final notifications with `SystemRuntimeAccess::take_data_notification` in `System::prepare_evaluation`, after ordered ingress commits and before evaluation readers. System runtime access and generated data parameters expose immutable `DataService`; component commit hooks expose `DataConsumerAccess` for demand changes only. Producer writes and policy changes remain at the exclusive Host boundary. Commit-time demand releases during deferred removal are supported; source compaction waits until the World's evaluation callbacks finish, including error cleanup. Large capacity contractions keep geometric append slack rather than retaining an old window's entire allocation. Read APIs cannot expire samples or advance time. World teardown releases only that World's consumers. Production transports and concrete binding systems provide their own maintained integration evidence; the core tests here establish local admission, retention and lifecycle invariants only.
