# Ordinary GUI Observations

The selected GUI System owns applied-effect identity and publication for its World. Input service instances, platform permits and request issuers do not own the application's observation stream. [GUI architecture](../../../../../../../docs/architecture/gui.md) defines momentary effects and pinned callback ancestry; [connection policy](../../../../../../../docs/architecture/protocol-and-schema.md#control-and-data-planes) defines failure isolation.

`GuiObservationOutput` is an independently closeable typed FIFO. Its connection-owned [reliable output account](../../../../services/reliable_output.rs) also accounts the adapter's existing replies and other reliable output; it is not an additional GUI allowance. The primitive contains no queue, protocol, message limit or clock. Output failure is latched without callbacks and requires the Host to disconnect that connection. A foreign observer's congestion cannot reject or roll back an already-applied action.

Create an output with callback-free encoding bounds, mint a whole-World subscription, and prepare `GuiObservationCommand::prepare_subscribe` with a one-entry lease from that same account. Enqueue it with `enqueue_system_command(GuiSystem::ID, session, command)`, not a second command-reply API. Preparing is inert. At the World mutation boundary the receiver retains Subscribe before activation; Unsubscribe removes the exact generation and retains its result behind already-retained effects. Dropping an unsettled prepared command retains its one cancellation result. These are ordering cuts, not acknowledgements of network receipt.

The FIFO contains both those control results and selected applied effects. Effects retain exact World/entity/component lifetime, source, actual mutation tick and logical ancestry. A World-local ordinal distinguishes repeated presses in one tick; request IDs are not effect identities. Value changes are not effects: clients observe them through lifecycle value members. A `GuiAction` command's press, submit or focus change is published at its mutation boundary, in ingress order with observation cuts, with the tick of the frame applying its batch. Actual changed focus and pointer feedback have separate subscription classes. Successful no-op terminals carry no effect ID and produce no observation. Automatic eligibility invalidation is not advertised as a complete feedback-event stream.

The receiver preflights an ordinal without consuming it, prepares the issuer's exact terminal, commits local state, then retains observations before terminal settlement can reenter. No foreign/application callbacks run during publication. A failed preparation consumes neither state nor ordinal. Removing every control does not reset the publisher. Durable GUI payloads exclude publisher ordinals, registrations and retained output; restored Worlds have fresh runtime identities.

Every output, subscription, registration, pending command and FIFO node retains its allocation charge. The FIFO uses two linked stacks with amortized constant-time operations and no uncharged vector spare capacity. Effect charges conservatively include shared ancestry and submitted text capacity for each destination, plus simultaneous encoded-buffer capacity from the adapter descriptor. Encoding must validate that descriptor against its actual allocation needs and wire limits. Overflow fails the destination connection explicitly.

Endpoint allocation credit is shared with every weak subscription reference, without retaining endpoint liveness. The private weak-reference wrapper drops its weak pointer before its shared credit. Dropping the final strong output therefore cannot release credit for an allocation still retained by subscription handles; dropping the last weak reference releases it. Neither closing nor retaining metadata can revive an endpoint.

`GuiObservationDelivery::into_parts` transfers the retained record and non-Clone lease together. Encode while retaining that lease; only after releasing the original payload may the adapter shrink the charge to its encoded outbox allocation. Moving between queues must not release and reacquire credit. Close does not erase outstanding lease usage. The adapter explicitly closes outputs on session release and processes the shared failure latch at a safe connection boundary.

The [real Host receiver tests](observation_tests.rs), [publisher accounting tests](publisher_tests.rs) and [shared reliable-output accounting tests](../../../../services/reliable_output_tests.rs) establish the headless core boundary. They do not establish production codec, transport, React callback, or native input routing coverage. Adapters must supply that evidence after coherent adoption. No historical momentary-effect replay is provided; reconnect requires fresh subscriptions, and reads cannot recover missed presses.
