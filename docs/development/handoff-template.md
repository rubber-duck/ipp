# Handoff Template

Append to Beads notes using multiline text input under the [coordination workflow](coordination.md). Link to source/design; include enough to resume independently.

```text
Task and state:
Owner / intended receiver:
Branch, worktree, integration base:
Commit / PR / uncommitted location:

Delivered behavior or decisions:
Architecture/strategy updates:

Validation:
- Exact command/scenario -> result
- Environment, fixture/build identity, artifacts
- Omitted checks -> reason

Open findings, blockers, risks:
Next concrete action:
Integration / acceptance required:
Last Dolt sync result (or local-only state):
```
