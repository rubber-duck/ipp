# Task Template

Fill this body in a temporary file before [creating a Beads task](workflow.md#claim-work). Keep live tracking in Beads.

## Goal

Current problem and concrete intended result.

## References

- Architecture: owning document/section.
- Strategy: relevant `docs/plans/` section.
- Prerequisites: Beads IDs; also create blocking edges.

## Scope

Files/subsystems, integration owner for shared interfaces, exclusions, branch/worktree and integration base. Fill location when claimed.

## Acceptance

Observable outcomes, including applicable failure/lifecycle behavior. Also fill the Beads acceptance field.

## Validation

Name real participants, reusable fixtures, observable assertions, rendering captures where applicable, and scenario/driver extensions under the [testing policy](integration-testing.md). List commands, environments, failure artifacts and supplementary unit tests. Record actual results only. Docs-only tasks name repository checks.

## Handoff

Record owner, location, completed work, open decisions and next action with the [handoff template](handoff-template.md).
