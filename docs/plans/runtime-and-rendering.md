## Host execution

Extend shared session policy and native/browser adapters through generic Host/World interfaces. Compile attachment traversal at structural boundaries and separate parent-first evaluation from child-first output assembly and root presentation. Supply scoped parent/view context without retained World borrows. Multiplex independent World sessions while keeping presentation selection explicit. Use real clients to verify parent/sibling progress during an open child batch on the same connection, attachment publication, expiry, pause/resume, congestion and teardown.

Implement the [Host task scheduler](../architecture/runtime.md#task-scheduling) with Smol components behind Host and I/O context handles. Drive ready Host tasks at the start of updates and from service-only wakeups when Worlds are paused or presentation is idle. Preserve World ordering and completion admission. Replace native per-connection thread/poll loops with Smol-compatible asynchronous WebSocket handling, retaining message framing, connection accounting and fairness. Keep browser WebSocket and fetch bridges, connecting completion and cancellation to Rust futures. Delegate native blocking I/O to a pool; select native HTTP and filesystem adapters by required streaming behavior, dependency cost and measured memory/copy overhead. Keep backend libraries out of core and native reactors out of browser builds.

Extend the maintained native WebSocket and worker/WASM drivers with gated I/O, paused and idle Hosts, cancellation and shutdown, and a task that repeatedly wakes itself. Observe execution context, continued peer/control progress, service completion without World advancement, and unchanged World mutation/evaluation order. Exercise real browser fetch and native transport traffic alongside rendering fixtures, keeping environment setup separate from reusable assertions. Validate the selected executor on actual browser WASM, and compare production/instrumentation native and WASM artifact costs before claiming footprint benefits.

## Asset transport

Extend generic sources/readers/writers and Host adapters together through the [asset boundary](../architecture/assets.md). Measure copies and retained representations before adding transports or shared memory. Keep World dependency accounting separate from resource loading, including applied effects of failed batches.

Redesign readers around awaitable minimum-length immutable windows and explicit consumption, without preserving the current copy-oriented interface. Keep consumer parsing independent of shared-memory versus stream backing. Preserve window ownership through I/O registration, cancellation and accounting wrappers; use scoped guards where backing needs a lease, and avoid per-read future allocations at dynamic provider boundaries. Make opening, listing and writing asynchronous as well, with incremental listing and explicit writer completion. Let native mappings and WASM-addressable shared memory lend ranges directly. Stream and external-JavaScript adapters fill reusable reader-owned storage, with capacity established before input copies. Separate transport progress and prefetch from contiguous lookahead, so a request spanning chunks cannot deadlock behind the transport window. Decode incrementally into final private representations with bounded scratch and work per progress turn; graphics and CPU consumers share each format's incremental decoder.

Extend the maintained native and worker/WASM asset scenarios with a process-published immutable mapping and JS-generated shared-buffer input. Run the same decoder and fixture assertions against shared-buffer and fragmented-stream readers, including windows spanning source chunks, final short input and partial consumption. Keep mapping setup and browser shared-memory prerequisites in environment drivers. Verify byte identity and completed rendering, publication/release ordering, cancellation and replacement with independent readers, and rejection of stale or invalid ranges. Measure source staging allocations and copied bytes separately from final decoded storage, proving that directly addressable ranges avoid staging copies and external JS buffers cross into WASM once into reusable reader storage without a second staging queue. Report actual memory mode and copy path instead of treating a shared buffer as proof of zero-copy access.

Exercise client-authored sources over a distinct bounded data-plane protocol on both worker and native connections. Verify immutable names, complete-only publication, session fencing, interrupted delivery, payloads larger than command framing, and source progress while a logical command batch is still open. Retained publications use the [asset lease contract](../architecture/assets.md#retention-and-recovery); test source revocation, unload and recovery, including independently live sibling demand. Use the same resource lifecycle and image assertions as externally acquired assets.

Implement [Host-to-client bulk reads](../architecture/protocol-and-schema.md#host-to-client-bulk-reads) as shared connection-owned transfer machinery used by contract discovery, World saves, captures and authorized asset exports. Preserve schema-independent bootstrap and move bulk bytes out of control replies. Keep read acknowledgement separate from physical delivery accounting, with explicit grant/revocation and detached-output lifetime. Extend native and worker scenarios with independent recipient leases, withheld acknowledgements, pressure and cancellation, continued peer/control progress, save/restore and completed capture comparisons. Round-trip supported CPU/GPU exports through real loaders; verify original-source reads survive decoded unload, unfinished dependent exports fail, and completed detached outputs survive source teardown.

Graphics providers receive narrow device dependencies at Host registration. Remove redundant representations after identifying actual CPU consumers; reload through the original I/O source instead of retaining encoded recovery copies in the asset layer. Keep source storage and caching in I/O providers. Built-ins and new formats use ordinary ingress and lifecycle paths. Exercise reload with provider reads observed, including cache hits and unavailable or replaced sources, to verify recovery without an asset-owned source copy.

Separate loss of consumer demand from destruction of reusable loaded content. Add Host-configurable idle retention through the existing catalog and release barrier, accounting measured bytes and ranking pressure-driven eviction by both size and recency. Validate repeated clip selection without reacquisition, active/shared demand protection, forced pressure and session-private source teardown. Gate real browser asset delivery while observing advancing animation poses and completed frames; fast local fixtures alone cannot establish smooth mode changes.
