# Font licences

Licence and provenance notices for the [shared font sources](../../assets/fonts/README.md). Source pins and download instructions live in `assets/fonts`; downloaded font binaries and converted assets stay under ignored `target/` directories.

Keep the following notices with redistributed fonts:

- Shure Tech Mono: [OFL](ShureTechMono-OFL.txt) and [upstream Nerd Fonts provenance](ShureTechMono-Nerd-Font-README.md).
- Adwaita Mono: [OFL](AdwaitaMono-OFL.txt).
- Noto Sans: [OFL](NotoSans-OFL.txt).

The gallery site packager includes the Shure notices with its shared runtime font.
