# SVG item animation conversion

`convert_svg_animation.py` converts one SVG into an ordinary static IPPD drawing and a JSON manifest containing bounded animation clips for the Surface item that uses that drawing. The generated client binds those tracks to the actual item name; the manifest contains no protocol or target-layout data. This is item-level Surface animation rather than an SVG playback engine. Animated opacity multiplies each painted path's coverage, so overlapping translucent paths do not use browser-style offscreen group-opacity compositing.

The static artwork uses the subset documented by `convert_surface_asset.py`. Animation elements must be direct children of the root `svg`. Supported elements are `animate attributeName="opacity"` and `animateTransform attributeName="transform" type="scale"`. They apply to the whole Drawing item rather than an SVG descendant.

Each animation needs a finite positive `dur` in `s` or `ms`, `fill="freeze"`, and either `values` or a complete `from`/`to` pair. `begin` may be `indefinite` or zero. `keyTimes` is optional. Linear values span the complete duration; discrete values begin at evenly divided intervals, so two values switch halfway through. An explicit linear `keyTimes` sequence must end at 1, while a discrete sequence may place its last change before the end. `calcMode` may be `linear` or `discrete`, which exports as `linear` or `step`. Opacity stays within 0..1; scale is one positive number or two positive numbers and exports as a two-element value.

Use `data-ipp-clip="name"` on an animation element to select its clip. Omitting it selects `default`. A clip may contain at most one opacity track and one scale track, and all its tracks must have the same duration.

Nested animation, event timing, nonzero offsets, repetition, additive or accumulated animation, easing, CSS animation, path morphing, and transform types other than scale are rejected. A static `transform` on the root is also rejected when the root has a scale animation because SVG replacement semantics would otherwise be lost; static transforms on descendants remain supported. The converter reports these cases instead of approximating their meaning. Static SVG conversion remains strict after supported animation elements are removed.

Run the converter directly with an SVG, IPPD destination, and animation JSON destination. `build_gallery_gui_assets.py OUTPUT_DIRECTORY` scans `examples/world-gallery/worlds/gui/authoring/svg/*.svg`, converts each source as a static drawing, and writes those drawings plus `assets.json`. The `gallery-gui-assets` prerequisite first exports the packed Blender projector into the output directory, then this converter indexes those payloads alongside the drawings. The gallery build also prepares the [shared font](../assets/fonts/README.md) under `target/font-assets`, independently of the terminal example.
